# 30. 게시판 — 공지사항 · FAQ · 자유게시판 · 댓글

게시판 정의는 `tb_boards`(V2 시드: `notice` 공지사항, `faq` 자주묻는질문, `free` 자유게시판). 관리자 측 화면은 [70-admin](70-admin.md).

## 30-1. 공지사항 `/user/notice`, FAQ `/user/faq` (읽기 전용)

**코드**: `user/pages/PostListPage.tsx` (`boardCode` prop). 상세는 같은 페이지 안에서 전환(URL 변화 없음).

- 목록: `GET /api/v1/public/posts/board/{boardCode}?page&size` — 번호·제목·등록일·조회. `noticeYn=Y` 글은 "공지" 태그.
- 상세: `GET /api/v1/public/posts/{id}` — 제목·날짜·조회수·본문(HTML). 상세 조회 시 조회수 +1. "← 목록으로".
- 비활성(`useYn=N`) 글은 목록에서 제외된다.

체크포인트: 관리자에서 공지 작성 → 사용자 목록·상세에 즉시 보임(2026-10-12 실측). 상세 2번 열면 조회수 2.

## 30-2. 자유게시판 `/user/free` (회원 글쓰기)

> 2026-10-13부터 **자유게시판 메뉴를 꺼 두었다**(V4: 사용자 메뉴 `/user/free` `use_yn=N`). 헤더·모바일 메뉴에서 빠지고 푸터에는 원래 없다. 라우트는 살아 있다. 다시 켜려면 관리자 **홈페이지 메뉴** 화면에서 스위치를 켠다([70-admin](70-admin.md)).

**코드**: `user/pages/FreeBoardPage.tsx`, 댓글 `user/components/CommentSection.tsx`.

- 목록·상세는 공지와 같은 공개 API. 하단에 댓글 수(`GET /api/v1/public/comments/post/{id}/count`).
- **글쓰기/수정/삭제는 로그인 회원만**: `POST /api/v1/user/posts/free`, `PUT|DELETE /api/v1/user/posts/{id}`. 본문은 CKEditor(이미지 업로드는 `/api/v1/user/files/upload`).
- **본인 글만** 수정·삭제 — 서버가 `reg_no`(작성자 회원 id)와 현재 회원을 비교(`PostService`). 남의 글이면 403/400.
- 비로그인으로 쓰기 API 호출 → `401 C004`(2026-10-12 수정 전에는 500).

## 30-3. 댓글 (익명, 비밀번호)

- 댓글은 **회원 로그인과 무관**하게 이름 + 비밀번호로 쓴다: `POST /api/v1/public/comments` `{postId, parentId?, authorName, password, content}`. 대댓글은 `parentId`.
- 수정 `PUT /api/v1/public/comments/{id}`, 삭제 `DELETE /api/v1/public/comments/{id}` — 본문에 `password`를 보내 일치해야 한다.
- 관리자는 `/admin/posts/free` 글 상세에서 댓글을 비밀번호 없이 삭제(`DELETE /api/v1/admin/comments/{id}`).

체크포인트: 비로그인으로 댓글 작성 성공. 틀린 비밀번호로 삭제 → 실패 메시지. 관리자 삭제 후 사용자 화면에서 사라짐.

## 의도적 미구현 / 알려진 문제

- 게시글 검색(사용자 화면) 없음. 관리자만 제목/내용 검색.
- 글 작성자 표시는 `regNo`→회원 조회로 이름을 붙인다(`PostResponse.author`). 탈퇴 회원의 글은 작성자가 비어 보일 수 있음(미확인).
- 댓글 비밀번호는 BCrypt로 저장(`CommentService`) — 복구 불가.
