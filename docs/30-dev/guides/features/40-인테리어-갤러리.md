# 40. 인테리어 갤러리 — 현장시공 · 셀프시공 · 인테리어스토리

**코드**: `user/pages/InteriorGalleryPage.tsx` (`category` prop: `ONSITE`·`SELF_TIP`·`STORY`). 라우트 `/user/interior/{onsite,self-tip,story}`. 엔티티 `Interior`(`tb_interiors`), 카테고리 enum `InteriorCategory`.

## 기능

- 카테고리별 카드 목록(대표 이미지 `thumbnailUrl`·제목·등록일·조회수), 3열 그리드, 페이지당 12건, 페이지네이션.
- 카드 클릭 → **모달**로 상세(제목·날짜·조회수·본문 HTML). URL은 바뀌지 않는다(딥링크 없음).
- 본문은 관리자 CKEditor 또는 [블로그 이관 도구](../blog-import.md)가 만든 HTML. 이관 글은 머리에 "네이버 블로그 원문 · 날짜 · 원문 보기" 링크와 `📍 수디자인 · 주소` 줄이 있다.

## 사용 API

- 목록 `GET /api/v1/public/interiors/category/{category}?page&size` — 정렬 `sortOrder` 오름차순, 같으면 id 내림차순(기본 sortOrder 0이라 사실상 최신 등록이 위). `useYn=Y`만(`InteriorRepository.findByCategoryAndUseYnOrderBySortOrderAscIdDesc`).
- 상세 `GET /api/v1/public/interiors/{id}` — 조회수 +1.

## 테스트 체크포인트

- 관리자 `/admin/interiors/onsite`에서 등록(이미지 없이도 가능) → `/user/interior/onsite` 첫 카드로 표시, 이미지 없으면 플레이스홀더.
- 상세 모달 열기 → 본문 이미지가 `/uploads/...`에서 200으로 로드(콘솔에 404/500 없음). 닫기 후 목록 유지.
- 2026-10-12 이관 결과: 현장시공 40 · 셀프시공 8 · 인테리어스토리 15, 본문에 `pstatic.net` 링크 0건, 대표 이미지 누락 0건.
- 관리자에서 "사용 안 함"으로 바꾸면 사용자 목록에서 빠짐.

## 의도적 미구현 / 알려진 문제

- 상세 딥링크(`/user/interior/onsite/{id}`)가 없어 공유·검색엔진 색인이 안 된다 → 6단계 SEO에서 라우트 추가.
- 원본 게시일은 본문 머리 텍스트로만 남는다(`reg_dt`는 이관 시각). 목록 정렬은 id 순.
- 블로그 이관 글의 동영상 1건은 "원문에서 확인" 안내로 대체.
