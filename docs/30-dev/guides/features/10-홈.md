# 10. 홈 (`/user`)

**코드**: `apps/frontend/src/user/pages/HomePage.tsx`(+ `HomePage.css`). `/`는 `/user`로 리다이렉트(`App.tsx`).

## 기능

- 히어로: 슬로건 "당신의 공간을 새롭게 디자인합니다" + 버튼 **시공사례 보기**(`/user/interior/onsite`)·**견적문의**(`/user/inquiry`).
- 서비스 안내: 현장시공·셀프시공·인테리어스토리 카드 → 각 갤러리로 이동.
- CTA: "인테리어 상담이 필요하신가요?" → `/user/inquiry`.
- 홈 진입 시 활성 팝업이 뜬다([00-공통](00-공통.md) 팝업 레이어).

## 사용 API

- 홈 자체는 API를 호출하지 않는다. 팝업 레이어만 `GET /api/v1/public/popups/active`.

## 테스트 체크포인트

- `/` → `/user` 리다이렉트, 히어로 버튼 2개가 각 경로로 이동.
- 서비스 카드 3개 링크가 `/user/interior/{onsite,self-tip,story}`.
- 팝업: 관리자에서 사용 중(`useYn=Y`)·노출 기간 내 팝업을 만들면 홈에서 뜨고, "하루동안 열지 않기" 후 새로고침해도 다시 안 뜬다(쿠키).
- 모바일 360px: 히어로 문구·버튼·카드가 세로로 쌓이고 가로 스크롤 없음(2026-10-12 확인).

## 의도적 미구현 / 알려진 문제

- 히어로 문구("당신의 공간을 새롭게 디자인합니다")는 코드에 고정. 대표 확정 문구를 받으면 교체([business.md](../../../00-common/business.md)).
- 메타: `index.html`의 title·description·og + `usePageMeta`가 페이지별로 갱신(6단계). 정적 프리렌더는 없어 JS를 실행하지 않는 크롤러는 기본 메타만 본다.
