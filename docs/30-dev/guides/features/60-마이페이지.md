# 60. 마이페이지 `/user/mypage` (로그인 회원)

**코드**: `user/pages/MyPage.tsx`, API `shared/api/endpoints/auth.ts`(`withdrawMember`).

## 기능

- 로그인 스토어(`authStore`)의 회원 정보(아이디·이름·이메일·가입 방식)를 **표시만** 한다. 수정 기능 없음.
- **회원 탈퇴**: 버튼 → 모달에서 비밀번호(+사유 선택) 입력 → `POST /api/v1/auth/withdraw` `{password, reason}` → 스토어 비우고 홈으로. 서버는 행을 지우지 않고 `Member.withdraw()`로 **개인정보를 익명화하고 `active=false`**로 바꾼다. LOCAL 가입자만 비밀번호를 검사하고 소셜 가입자는 비밀번호 없이 탈퇴된다(`MemberService.withdrawMember`).
- 비로그인(토큰 없음)으로 접근하면 `/user/login`으로 보낸다(6단계).

## 사용 API

- `POST /api/v1/auth/withdraw` — 인증 필요(`/auth/withdraw`는 접두어 규칙상 로그인 필수).

## 테스트 체크포인트

- 가입 → 로그인 → 마이페이지에 아이디·이름 표시 → 탈퇴(비밀번호 일치) → 로그인 시도 시 실패. (`MemberFlowTest`)
- 틀린 비밀번호로 탈퇴 → 실패 메시지, 계정 유지.

## 의도적 미구현 / 알려진 문제

- 정보 수정·비밀번호 변경 없음(관리자는 `/admin/users`에서 비밀번호 초기화 가능).
