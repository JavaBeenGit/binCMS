## 구현 (브랜치 `refactor/관리자-화면-분할`)

- `user/components/ArticleView.tsx`(+css): 글 한 편 공통 틀 — 목록 링크, 제목(배지), 날짜·조회수, 본문(`ck-content`), 하단 **목록으로**·**주소 복사**.
- `user/pages/InteriorDetailPage.tsx`: `/user/interior/{slug}/:id`. 없는 id → 안내 후 목록. 탭 제목 "글 제목 - 카테고리 | 수디자인".
- `user/pages/InteriorGalleryPage.tsx`: 모달·상세 조회 제거. 보던 페이지를 `?page=`에 두고, 카드 클릭 시 `state.from`으로 목록 주소를 넘겨 "목록으로"가 그 페이지로 돌아간다.
- `user/pages/PostDetailPage.tsx`: `/user/notice/:id`. `PostListPage`는 `variant='list'|'accordion'` — 공지는 목록→상세 페이지, FAQ는 antd `Collapse` 아코디언(질문 클릭 → 답 펼침, 조회수는 안 올라감).
- 백엔드 `sitemap.xml`: 공지사항 상세 `/user/notice/{id}` 추가, 꺼 둔 `/user/free` 제외 (`PostRepository.findByBoard_BoardCodeAndUseYnOrderByIdDesc`, `SitemapTest` +1).
- 관리자 시공사례 상세 모달에 "홈페이지에서 보기"(새 탭) 버튼.
- `shared/constants/interior.ts`: 카테고리 ↔ URL 조각(백엔드 SLUG 와 동일 규칙).

## 후속 (배포 뒤 — 잊지 말 것)

- **카카오톡·페이스북 링크 미리보기**: 이 사이트는 SPA 라 크롤러가 `<meta og:*>`를 못 본다(JS 실행 안 함). 배포(8단계) 뒤 nginx 또는 백엔드에서 `/user/interior/{slug}/{id}`·`/user/notice/{id}`에 대해 **서버 측 OG 태그(제목·설명·대표 이미지)를 넣는 프리렌더/미들웨어**를 붙인다. 설계서 §8-1 행 6의 "프리렌더는 후속"과 같은 건.
